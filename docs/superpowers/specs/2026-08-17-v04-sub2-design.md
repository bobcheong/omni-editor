# v0.4 Sub-project 2: Remaining UX Features (F-07 through F-16) — Design Spec

**Date:** 2026-08-17
**Issue:** #16
**Status:** Approved

## Goal

Implement all remaining v0.4 features: word-level merge, hex view, compare bookmarks, swipe navigation, symbol outline, report completion, session groups, theme editor, accessibility pass, and platform surfaces.

## Group A: Core logic + UI (JVM-testable)

### F-10 — Word-level merge
- `MergeEngine.mergeWordLevel(leftLine: String, rightLine: String, selections: List<WordSelection>): String` in `core/diff`
- `WordSelection(range: IntRange, source: Side)` — which word segments to take from which side
- Active-line sheet: per-word-segment tap toggles selection between left/right
- Apply via `document.edit()` as single undo step

### F-11 — Symbol outline + bracket matching
- `SymbolExtractor.extract(lines: List<String>, grammar: Grammar): List<SymbolInfo>` in `core/diff/syntax`
- `SymbolInfo(name: String, kind: SymbolKind, line: Long)` — FUNCTION, CLASS, PROPERTY
- Scans tokens for declaration patterns (e.g., `fun name`, `class name`, `def name`)
- `BracketMatcher.findMatch(text: String, position: Int): Int?` — returns matching bracket position
- Both disabled above full-index threshold

### F-12 — Report completion
- `ReportGenerator.htmlSideBySide(meta, leftLines, rightLines, hunks, scope): String`
- `ReportScope` enum: ALL, SELECTION, VISIBLE
- All report methods gain `scope` parameter (default ALL for backward compat)
- Header/footer include rules summary + engine mode
- PDF scaffold: `PrintManager.print("Omni Editor Report", printAdapter, null)`

### F-13 — Session groups + JSON export
- `SessionStore.createGroup(name): SessionGroup`, `deleteGroup(id)`, `addToGroup(groupId, sessionId)`, `removeFromGroup(groupId, sessionId)`, `listGroups(): List<SessionGroup>`
- `SessionStore.exportAsJson(sessionId): String` — full session with sources, rules, bookmarks
- `SessionStore.importFromJson(json: String): Session` — validates schemaVersion, creates session
- Search already exists in SessionStore

## Group B: UI composables (compile-verifiable)

### F-07 — Hex view
- `HexGrid` composable in `design` module accepting `ByteArray` source + `HexViewConfig`
- LazyColumn with `HexRow` items: address (hex/dec), hex bytes, ASCII column
- Bytes per row adapts: 8 (narrow), 16 (default), 32 (wide)
- Editor toggle: "View as hex" in overflow menu
- Read-only for now (F-18b adds editing at v0.6)

### F-08 — Compare bookmarks
- Add `bookmarks: List<CompareBookmark>` to `Session` data class
- Gutter bookmark icon on bookmarked lines
- Long-press line number to add/remove bookmark
- Next/prev bookmark navigation buttons
- New `CompareUiState` variant for "differences only in ignored content"

### F-09 — Swipe diff-to-diff
- Fling-at-bound detector on `HorizontalScrollController`
- When `offsetPx == 0` (left bound): left fling → previous diff
- When `offsetPx == maxOffsetPx` (right bound): right fling → next diff
- Word-wrap mode: all horizontal flings trigger diff navigation

### F-14 — Theme editor
- Settings section: list of themes (built-in + user)
- Create/edit: colour pickers for each `TokenType`
- Preview panel showing sample code with applied colours
- JSON import/export via `UserTheme` serialization

### F-15 — Accessibility
- `contentDescription` on every diff row: "{side} line {n}, {changeType}"
- `semantics { }` blocks on merge buttons, find bar, tab strip
- `Modifier.clearAndSetSemantics` for decorative elements
- Scaffold: Gradle task that runs lint a11y checks

### F-16 — Platform surfaces
- App shortcuts via `ShortcutManagerCompat`: "New compare", "Open editor"
- Quick-settings tile: `CompareClipboardTile extends TileService` — scaffold

## Constraints
- `core/model` and `core/diff` must not import `android.*`
- Both flavours must build
- No new dependencies
- Tests in same commit as code
